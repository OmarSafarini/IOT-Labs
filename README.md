# IOT-Labs
## Lab-1 : 

### This project uses an ESP32 and a DHT22 sensor to measure temperature and humidity. The readings are sent to ThingSpeak via Wi-Fi every 20 seconds and displayed on cloud-based charts for real-time monitoring.
